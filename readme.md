# 🌌 AI-Based Exoplanet Detection & Exploration

> An AI-driven space exploration platform that detects distant exoplanets from light curve data and transforms composition analysis of exoplanets into an interactive experience.

---

## 🚀 Project Overview

Our project combines machine learning with immersive UI / UX and web interface to make NASA / TESS exoplanet's composition data accessible and engaging. Users can analyze real astronomical data from NASA's own dataset while a locally run AI compiles it into text form for users to navigate an interactive storyline.

---

## 🎮 Game Story & Key Features

* **AI-Powered Generation:** Pre-trained LLM Astrosage generates a text of containing composition of selected exoplanet.
* **Interactive Storyline:** Step into the shoes of a deep-space researcher discovering new worlds & their composition through interactive gameplay mechanics.
* **Immersive UI/UX:** High-fidelity dashboard and visuals tailored for effortless navigation and data visualization.

---

## 🛠️ Tech Stack

* **Frontend & UI:** React, Vite, HTML/CSS
* **Backend & AI:** Python, FastAPI, Data Analysis Libraries
* **LLM & Data for Astronomy:** Astrosage 8B model, NASA Exoplanet Archive

---

## ⚡ Quickstart (Run Locally)

### Type the below one by one:
```bash
git clone [https://github.com/gakerion/AI-Based-Exoplanet-Detection.git](https://github.com/gakerion/AI-Based-Exoplanet-Detection.git)
cd AI-Based-Exoplanet-Detection 
cd front end
npm install
npm run dev

```
